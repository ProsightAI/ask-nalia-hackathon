# Product Provenance

## Pre-existing work

Before the Elevate Women Global Hackathon 2026:

- **ProsightAI** existed as the parent company and technology platform.
- **PMI Hormonal Health** existed as the broader women's hormonal-health product vision.
- General cloud and service accounts existed.

## Hackathon work

Ask Nalia was developed as a focused **Hormone Interaction Intelligence** prototype during the hackathon.

The project-specific work included:

- user journey
- Hormone Interaction Map
- backend/API contracts
- evidence schema
- deterministic safety verifier
- frontend experience
- report experience
- optional voice interface
- automated tests
- project documentation

## Continuing product direction

Ask Nalia is intended to integrate into PMI Hormonal Health while preserving clear capability boundaries:

- **Ask Nalia**: symptom/story understanding, adaptive questions, hormone-interaction reasoning
- **AMIRA**: medication intelligence
- **ProsightAI**: supported physiological measurement
- **PMI Hormonal Health**: consumer-facing orchestration

This repository is a curated public showcase, not the private production source tree.
